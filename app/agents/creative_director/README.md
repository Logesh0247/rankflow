# Creative Director — BUILT (Prompt 07)

Creative Director Agent — storytelling, hooks, narration, countdown
structure, transitions, editing plans.

Deterministic template generator (`deterministic_template_v1`): it
loads the job's five ranked moments, scores several hook
candidates, builds a #5-to-#1 countdown storyboard, writes
signal-grounded narration, defines the visual direction and
caption plan, and emits a structured Edit Decision List.

Honest limit, stated in `docs/CREATIVE_DIRECTOR.md`: there is no
vision-language model in this environment, so the narration never
names what happens in a scene. It describes only what Video
Intelligence measured — motion, sharpness, brightness, clarity,
duration — plus the user-supplied topic and the provider-published
source title/creator shown on screen. A semantic event label
would be a fabrication, so none is ever produced.
